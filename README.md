# MariowithaD Artist Site

Create a functional responsive music artist website called MariowithaD, stylistic direction Creative Record Store. Hero is cinematic dark blue and black underground recording studio featuring artist in green helmet, using attached imagery if available, with small subtle edgy lowercase 'mariowithaD' editorial grotesk/monospace typography. NO Avengers/superhero oversized metallic or sci-fi logo. Five navigation anchors/sections: Home immersive full screen hero, Releases filterable vinyl-cover gallery with original productions vs collaborations vs genre exploration, About with approved biography, Mixes with three Coming Soon mix cards, Contact with social and collaboration link placeholders. Two confirmed releases with valid URLs: 'The More You Know' https://soundcloud.com/mariowithad/the-more-you-know and 'Hug Yah' https://soundcloud.com/mariowithad/hug-yah . Do not invent any other released tracks or collaborations or links. Approved bio: 'A lifelong music head shaped by jazz, hip hop, house, funk and soul. From digging records at 18 to running live sound in London, the foundation was built early. Production started in 2020 — years spent experimenting and refining. Now at 31, it’s time to release.' Aesthetic: charcoal black/silver subdued blue, tiny warm amber, tactile record-store editorial, minimal hover microanimations and scroll reveal, 1 responsive navigation, accessibility reduced motion, real clickable links, embed SoundCloud players where appropriate, avoid fake working playback. Make it a working website, not static image, deployable and easy to update for TuneCore releases. User has several artworks for future integration; use tasteful placeholder sleeves if inaccessible. Do not publish publicly without permission.
